## Français

### L’application

My App Launcher réunit un compagnon de configuration et un widget macOS pour ouvrir vos applications et vos sites en un clic. Choisissez les applications à afficher, personnalisez leur ordre et leur présentation, puis parcourez les pages du widget avec les flèches.

**Prérequis :** Mac Apple Silicon et macOS 27 ou ultérieur. L’interface est en français. Les images personnalisées doivent être carrées, mesurer au maximum 1024 × 1024 pixels et peser au plus 1 Mo.

### Installer

1. Téléchargez la dernière version depuis [GitHub Releases](https://github.com/CocoZillAaa/MyAppLauncher/releases/latest), décompressez-la et glissez **MyAppLauncher.app** dans **Applications**.
2. Ouvrez l’app et ajoutez les applications ou liens souhaités. Si la fenêtre de configuration ne s’affiche pas, choisissez **Configurer…** dans le menu de l’app.
3. Cliquez sur le bureau avec le bouton droit, choisissez **Modifier les widgets…**, cherchez **MyAppLauncher** et ajoutez le format voulu.

Cette app est signée Apple Development et n’est pas notarisée. Si macOS bloque son ouverture, essayez de la lancer, puis choisissez **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**. [Aide Apple sur l’ouverture d’apps](https://support.apple.com/fr-fr/102445).

### Mises à jour et nouveautés

Dans le compagnon, choisissez **Mises à jour → Rechercher une mise à jour…**. Vous pouvez aussi activer la recherche automatique ; elle fonctionne quand le compagnon est ouvert. Chaque installation demande votre confirmation.

Les nouveautés de chaque version sont publiées dans les [notes de version GitHub](https://github.com/CocoZillAaa/MyAppLauncher/releases). Pour compiler l’app ou contribuer au code, consultez le [guide de contribution](CONTRIBUTING.md).

## English

### The app

My App Launcher combines a configuration companion with a native macOS widget for opening apps and websites in one click. Choose which apps to show, arrange and customize them, then move between widget pages with the arrows.

**Requirements:** Apple Silicon Mac and macOS 27 or later. The app interface is in French. Custom images must be square, no larger than 1024 × 1024 pixels and 1 MB.

### Install

1. Download the latest version from [GitHub Releases](https://github.com/CocoZillAaa/MyAppLauncher/releases/latest), extract it and drag **MyAppLauncher.app** into **Applications**.
2. Open the app and add the apps or links you want. If the configuration window does not appear, choose **Configurer…** from the app menu.
3. Right-click the desktop, choose **Edit Widgets…**, search for **MyAppLauncher** and add a size.

This app is Apple Development signed and not notarized. If macOS blocks it, try opening it, then choose **System Settings → Privacy & Security → Open Anyway**. [Apple’s help for opening apps](https://support.apple.com/en-us/102445).

### Updates and release notes

In the companion, choose **Mises à jour → Rechercher une mise à jour…**. You can also turn on automatic checks; they run while the companion is open. Every installation asks for your confirmation.

Changes for each version are listed in [GitHub Releases](https://github.com/CocoZillAaa/MyAppLauncher/releases). To build the app or contribute code, see the [contribution guide](CONTRIBUTING.md).
